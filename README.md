# MyCalculator

A simple pocket calculator with a sense of humor. Easy calculations get roasted, while harder ones earn a little respect.

Built with HTML, CSS, and JavaScript.

## Live Demo

[Open MyCalculator](https://calculatorabuser.netlify.app)

## Features

- Addition, subtraction, multiplication, and division
- Decimal and percentage support
- Clear and backspace buttons
- Keyboard support
- Responsive calculator layout
- Funny feedback for simple or difficult calculations

## Run Locally

Clone the repository and open `index.html` in your browser:

```bash
git clone https://github.com/MAbdullahGp/mycalculator.git
```

No installation or build step is required.

## Controls

- `C` — Clear
- `⌫` — Backspace
- `%` — Percentage
- `+`, `-`, `*`, `/` — Operators
- `Enter` or `=` — Calculate
- `Escape` — Clear

## Tech Stack

- HTML
- CSS
- JavaScript
- Tailwind CSS CDN
